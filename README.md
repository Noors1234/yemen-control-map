# Yemen Control Map

A simple static GitHub Pages site showing territorial control data for Yemen.

## Features

- Real-time dashboard displaying territorial control across Yemen's governorates
- Color-coded regions by control status
- Responsive design for desktop and mobile
- Easy data updates via JSON file

## Files

- `index.html` — Main interactive dashboard
- `yemen-control-state.json` — Source data for the map
- `.nojekyll` — Disables Jekyll processing for GitHub Pages
- `.github/workflows/deploy.yml` — Automatic deployment workflow

## How to Update Data

Edit `yemen-control-state.json` and push to main branch. The site will automatically redeploy.
